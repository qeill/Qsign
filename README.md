# APK一键签名工具 - 原生版

## 程序简介

APK一键签名工具原生版是一个基于C语言和OpenSSL库开发的APK签名工具，不依赖Java的keytool和jarsigner工具，直接使用OpenSSL库实现RSA密钥生成、SHA哈希计算和APK签名功能。该工具提供了两种版本：

- **apksigner_native**：终端版，适合命令行操作和自动化脚本使用
- **apksigner_gui_native**：GUI版，适合不熟悉命令行操作的用户使用

## 使用方法

### 终端版

#### 命令行参数

apksigner_native.exe [选项] <APK文件路径>

选项：
  -h, --help          显示帮助信息
  -v, --version       显示版本信息
  -p, --private <路径> 使用指定的私钥文件（.pem格式）
  -u, --public <路径>  使用指定的公钥文件（.pem格式）
  -o, --output <路径> 输出签名后的APK路径
  -g, --generate      自动生成密钥对
  -f, --force         强制覆盖输出文件
  -a, --alias <别名>   密钥别名（用于生成密钥文件）
  -l, --length <长度>  密钥长度（1024/2048/4096，默认2048）
  -t, --verify        验证APK签名
  -c, --cert <路径>    公钥证书路径（用于验证签名）
```

#### 示例用法

1. **自动生成密钥对并签名APK**
   ```bash
   apksigner_native.exe -g -o signed.apk app.apk
```

2. **使用已有密钥文件签名APK**
   ```bash
   apksigner_native.exe -p private.pem -u public.pem -o signed.apk app.apk
   ```

3. **验证APK签名**
   ```bash
   apksigner_native.exe -t -c public.pem app.apk
   ```

### GUI版

#### 运行程序

直接双击`apksigner_gui_native.exe`文件即可运行程序。

#### 界面说明

程序界面包含以下主要部分：

1. **文件选择区**：
   - APK文件：选择要签名的APK文件
   - 私钥文件：选择私钥文件（.pem格式）
   - 公钥文件：选择公钥文件（.pem格式）
   - 输出APK：设置签名后的APK输出路径

2. **密钥设置区**：
   - 自动生成密钥对：勾选此项将自动生成RSA密钥对
   - 密钥别名：设置生成密钥的别名
   - 密钥密码：设置生成密钥的密码
   - 密钥长度：选择RSA密钥长度（1024/2048/4096）

3. **操作按钮区**：
   - 生成密钥对：生成新的RSA密钥对
   - 签名APK：对选定的APK文件进行签名
   - 验证签名：验证APK文件的签名

4. **状态栏**：
   - 显示当前操作状态
   - 显示详细的进度信息

#### 使用步骤

1. **自动生成密钥对并签名APK**
   - 勾选「自动生成密钥对」复选框
   - 填写密钥别名和密码
   - 选择密钥长度
   - 点击「浏览...」按钮选择要签名的APK文件
   - 点击「签名APK」按钮开始签名

2. **使用已有密钥文件签名APK**
   - 取消勾选「自动生成密钥对」复选框
   - 选择私钥文件和公钥文件
   - 选择要签名的APK文件
   - 点击「签名APK」按钮开始签名

3. **验证APK签名**
   - 选择要验证的APK文件
   - 选择公钥文件
   - 点击「验证签名」按钮开始验证

## 工作原理

1. **密钥生成**：使用OpenSSL库生成RSA密钥对，包括私钥和公钥
2. **APK解析**：解析APK文件（ZIP格式），提取所有文件条目
3. **哈希计算**：对APK中的每个文件计算SHA256哈希值
4. **创建签名块**：创建META-INF/MANIFEST.MF、META-INF/CERT.SF和META-INF/CERT.RSA文件
5. **签名生成**：使用私钥对CERT.SF文件进行RSA签名
6. **更新APK**：将签名文件添加到APK中，完成签名

## 注意事项

1. 确保OpenSSL库已正确安装和配置
2. 密钥文件和APK文件路径中不要包含特殊字符
3. 签名后的APK文件会覆盖原文件（除非指定了不同的输出路径）
4. 自动生成的密钥文件会保存在当前目录下，请注意备份
5. 建议使用2048位或4096位密钥长度，提高安全性
6. 支持的APK格式为标准ZIP格式，不支持特殊压缩格式
7. GUI版程序已解决字体乱码问题，支持Unicode字符显示
8. 程序运行过程中请勿关闭窗口，否则可能导致APK文件损坏
9. 签名大型APK文件时可能需要较长时间，请耐心等待

## 文件说明

### 核心文件

- `apksigner_native.c`：终端版主程序文件
- `apksigner_gui_native.c`：GUI版主程序文件
- `sign_utils.c`：签名工具函数，包含RSA密钥生成、SHA哈希计算和签名验证功能
- `sign_utils.h`：签名工具头文件，定义了相关的数据结构和函数原型
- `zip_utils.c`：ZIP文件处理函数，包含APK文件的解析和修改功能
- `zip_utils.h`：ZIP文件处理头文件，定义了相关的数据结构和函数原型

### 构建脚本

- `build_native.bat`：终端版构建脚本
- `build_gui_native.bat`：GUI版构建脚本
