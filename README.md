# Qsign -  APK一键签名工具 - 原生版

## 程序简介

APK一键签名工具原生版是一个基于C语言和OpenSSL库开发的APK签名工具，不依赖Java的keytool和jarsigner工具，直接使用OpenSSL库实现RSA密钥生成、SHA哈希计算和APK签名功能。该工具提供了两种版本：

- **qsign**：终端版，适合命令行操作和自动化脚本使用
- **qsign-gui**：GUI版，适合不熟悉命令行操作的用户使用

## 功能特点

### 共同特点

- ✅ 不依赖Java工具包，独立运行
- ✅ 极其小巧便携只有88KB
- ✅ 基于OpenSSL库，支持现代加密算法
- ✅ 支持自动生成RSA密钥对
- ✅ 支持使用已有的私钥和公钥文件
- ✅ 支持自定义密钥别名和密码
- ✅ 支持验证APK签名
- ✅ 支持V1 JAR签名格式
- ✅ 支持SHA1和SHA256哈希算法
- ✅ 支持选择密钥长度（1024/2048/4096）
- ✅ 支持Windows、Linux、macOS等多平台
- ✅ 支持UTF-8编码的文件名

### 终端版特点

- ✅ 命令行界面，适合自动化脚本使用
- ✅ 支持批量处理
- ✅ 适合服务器环境使用
- ✅ 运行高效，资源占用少

### GUI版特点

- ✅ 直观的图形用户界面，操作简单易用

- ✅ 支持中文界面，适合中文用户使用

- ✅ 实时显示操作状态和详细进度信息

- ✅ 为所有控件添加了工具提示

- ✅ 支持Unicode字符显示，解决了字体乱码问题

- ✅ 适合不熟悉命令行操作的用户

  


## 使用方法

### 终端版

#### 命令行参数

qsign.exe [选项] <APK文件路径>

选项：
  -h, --help          显示帮助信息
  -v, --version       显示版本信息
  -p, --private <路径> 使用指定的私钥文件（.pem格式）
  -u, --public <路径>  使用指定的公钥文件（.pem格式）
  -o, --output <路径> 输出签名后的APK路径
  -g, --generate      自动生成密钥对
  -f, --force         强制覆盖输出文件
  -a, --alias <别名>   密钥别名（用于生成密钥文件）
  -l, --length <长度>  密钥长度（1024/2048/4096，默认2048）
  -t, --verify        验证APK签名
  -c, --cert <路径>    公钥证书路径（用于验证签名）
```
示例用法
#windows用户
qsign.exe -g -o signed.apk app.apk
#Linux用户
./qsign -g -o signed.apk app.apk
#Linux运行报错请执行以下命令，为程序赋予权限
chmod +x qsign
```

2. **使用已有密钥文件签名APK**
   ```bash
   qsign.exe -p private.pem -u public.pem -o signed.apk app.apk
   ```

3. **验证APK签名**
   ```bash
   qsign.exe -t -c public.pem app.apk
   ```

### GUI版(不支持Linux)

#### 运行程序

直接双击`qsign-gui.exe`文件即可运行程序。

#### 界面说明

程序界面包含以下主要部分：

1. **文件选择区**：
   - APK文件：选择要签名的APK文件
   - 私钥文件：选择私钥文件（.pem格式）
   - 公钥文件：选择公钥文件（.pem格式）
   - 输出APK：设置签名后的APK输出路径

2. **密钥设置区**：
   - 自动生成密钥对：勾选此项将自动生成RSA密钥对
   - 密钥别名：设置生成密钥的别名
   - 密钥密码：设置生成密钥的密码
   - 密钥长度：选择RSA密钥长度（1024/2048/4096）

3. **操作按钮区**：
   - 生成密钥对：生成新的RSA密钥对
   - 签名APK：对选定的APK文件进行签名
   - 验证签名：验证APK文件的签名

4. **状态栏**：
   - 显示当前操作状态
   - 显示详细的进度信息

#### 使用步骤

1. **自动生成密钥对并签名APK**
   - 勾选「自动生成密钥对」复选框
   - 填写密钥别名和密码
   - 选择密钥长度
   - 点击「浏览...」按钮选择要签名的APK文件
   - 点击「签名APK」按钮开始签名

2. **使用已有密钥文件签名APK**
   - 取消勾选「自动生成密钥对」复选框
   - 选择私钥文件和公钥文件
   - 选择要签名的APK文件
   - 点击「签名APK」按钮开始签名

3. **验证APK签名**
   - 选择要验证的APK文件
   - 选择公钥文件
   - 点击「验证签名」按钮开始验证
